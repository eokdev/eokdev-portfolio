# Emmanuel Olorunshola. Portfolio

Flutter web portfolio for Emmanuel Olorunshola (`eokdev`), a Flutter engineer based in Abuja.

## Run

```bash
flutter pub get
flutter run -d chrome
```

Hot reload with `r`, hot restart with `R` in the terminal that launched Chrome.

## Build

```bash
flutter build web --release --csp --no-web-resources-cdn
```

The release output is in `build/web`.
